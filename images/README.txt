Высота отрисовки: шапка 52 px (моб.) / 66 px (десктоп), меню 44/48 px, подвал 42/50 px.

с любым фоном. Если пришлёте PNG с прозрачностью, подложку можно убрать.

Высота отрисовки: 14 px (моб.) / 16 px (десктоп) — файл делать высотой 90-120 px.
Прозрачный фон, цвет тёмно-синий #051045 или чёрный. Поля обрезать под ноль.
